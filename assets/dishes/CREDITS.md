# Photos des plats de démonstration

Ces images illustrent uniquement les plats de démo (`demo-d1` … `demo-d10`) quand aucune photo n’est enregistrée sur le plat. Elles ne sont pas écrites dans AsyncStorage. Une photo ajoutée par un cuisinier reste celle qui s’affiche.

Chaque fichier est un WebP 800×450 (16:9), recadré pour que le plat remplisse la carte. Le fichier dérivé reste sous la même licence que l’original.
